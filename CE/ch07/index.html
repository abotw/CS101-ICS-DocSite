    Chapter 7: Programming and Languages

    7.1 Introduction to Programming

    Word Part of Speech Chinese Meaning Example Sentence Note
    programming n. 程序设计 Programming is the process of writing instructions for a computer. Core concept of software creation.
    programmer n. 程序员 A programmer writes and tests computer code. Also called developer.
    coding n. 编码 Coding involves translating logic into programming language syntax. Informal term for programming.
    source code n. 源代码 Source code is written in human-readable form. Text before compilation.
    algorithm n. 算法 An algorithm is a step-by-step procedure to solve a problem. Foundation of programming logic.
    logic n. 逻辑 Logical thinking is essential for programming. Related to flow control.
    syntax n. 语法 Each programming language has its own syntax. Rules for writing valid code.
    semantics n. 语义 Syntax defines form; semantics defines meaning. The “logic” behind syntax.
    debugging n. 调试 Debugging is the process of finding and fixing code errors. From “bug” (error).
    execution n. 执行 Program execution begins with the main function. Running a program.

    7.2 Types of Programming Languages

    Word Part of Speech Chinese Meaning Example Sentence Note
    machine language n. 机器语言 Machine language is directly understood by the CPU. Binary code of 0s and 1s.
    assembly language n. 汇编语言 Assembly language uses mnemonic codes for instructions. Low-level programming.
    high-level language n. 高级语言 Python and Java are high-level languages. Human-readable syntax.
    low-level language n. 低级语言 Low-level languages provide direct hardware control. Includes assembly and machine code.
    procedural language n. 过程式语言 C is a procedural programming language. Uses functions and procedures.
    object-oriented language n. 面向对象语言 Java and C++ support object-oriented programming. Based on classes and objects.
    functional language n. 函数式语言 Lisp and Haskell are functional languages. Emphasize pure functions.
    scripting language n. 脚本语言 JavaScript and Python are common scripting languages. Interpreted languages.
    markup language n. 标记语言 HTML is a markup language used for web pages. Describes structure, not logic.
    domain-specific language n. 领域特定语言 SQL is a domain-specific language for databases. Specialized purpose.

    7.3 Structure of a Program

    Word Part of Speech Chinese Meaning Example Sentence Note
    statement n. 语句 Each statement tells the computer to perform an action. Basic unit of execution.
    expression n. 表达式 An expression produces a value when evaluated. e.g., a + b.
    variable n. 变量 A variable stores data in memory. Has a name and type.
    constant n. 常量 Constants hold fixed values that do not change. Declared once.
    data type n. 数据类型 Common data types include int, float, and string. Defines value format.
    function n. 函数 A function performs a specific task in a program. May return a value.
    parameter n. 参数 Parameters pass data into a function. Defined in function declaration.
    return value n. 返回值 A function may return a value to the caller. Output of a function.
    block n. 代码块 A block groups multiple statements. Defined by braces {} or indentation.
    comment n. 注释 Comments explain code for human readers. Ignored by the compiler.

    7.4 Compilation and Interpretation

    Word Part of Speech Chinese Meaning Example Sentence Note
    compiler n. 编译器 The compiler translates source code into machine code. e.g., GCC, Clang.
    compile v. 编译 The program must be compiled before execution. Prepares for running.
    interpreter n. 解释器 The Python interpreter runs code line by line. Executes directly.
    interpret v. 解释执行 Interpreted languages are slower but flexible. Runtime execution.
    assembly n. 汇编 Assembly converts machine instructions into readable form. Used in low-level control.
    linking n. 链接 Linking combines object files into an executable. Step after compilation.
    executable n./adj. 可执行文件；可执行的 Executable files can be run by the operating system. e.g., .exe, .out.
    runtime n. 运行时 Errors that occur during runtime must be handled properly. Execution phase.
    syntax error n. 语法错误 Syntax errors prevent the program from compiling. Detected by compiler.
    semantic error n. 语义错误 Semantic errors occur when logic is incorrect. Detected at runtime or logically.

    7.5 Control Structures

    Word Part of Speech Chinese Meaning Example Sentence Note
    sequence n. 顺序结构 Instructions are executed in a sequence by default. Basic program flow.
    condition n. 条件 If the condition is true, the program executes a branch. Boolean expression.
    decision n. 决策 Decision structures use if–else statements. Conditional control.
    loop n. 循环 A loop repeats a block of code multiple times. For or while loops.
    iteration n. 迭代 Each repetition of a loop is an iteration. Related to looping.
    branching n. 分支 Branching changes the flow of control. Includes if, switch, case.
    boolean adj. 布尔的 Boolean values are true or false. Logical data type.
    comparison operator n. 比较运算符 Comparison operators test conditions like == or >. Used in control flow.
    logical operator n. 逻辑运算符 Logical operators include AND, OR, and NOT. Combine conditions.
    nested structure n. 嵌套结构 Nested loops can make programs more complex. Loop or condition inside another.

    7.6 Data Handling and Input/Output

    Word Part of Speech Chinese Meaning Example Sentence Note
    input n./v. 输入 The program waits for user input. Data entered by user.
    output n./v. 输出 The program prints output to the screen. Displayed results.
    read v. 读取 The program reads data from a file. Input operation.
    write v. 写入 Data can be written to disk files. Output operation.
    file n. 文件 Files are used to store permanent data. e.g., text, binary.
    open v. 打开 Open the file before reading or writing. File operation.
    close v. 关闭 Always close files after use. Prevents data loss.
    stream n. 数据流 Streams handle input and output data. Used in I/O libraries.
    buffer n. 缓冲区 Buffers temporarily hold data during transfer. Improves efficiency.
    exception handling n. 异常处理 Exception handling prevents crashes when errors occur. e.g., try–catch.

    7.7 Object-Oriented Programming (OOP)

    Word Part of Speech Chinese Meaning Example Sentence Note
    object n. 对象 An object represents an instance of a class. Contains data and behavior.
    class n. 类 A class defines the structure of objects. Blueprint for objects.
    method n. 方法 Methods define the behavior of a class. Functions inside a class.
    attribute n. 属性 Attributes store data within an object. Also called “fields.”
    constructor n. 构造函数 The constructor initializes new objects. Called automatically.
    inheritance n. 继承 Inheritance allows new classes to reuse existing code. OOP principle.
    polymorphism n. 多态 Polymorphism allows methods to behave differently. Enables flexibility.
    encapsulation n. 封装 Encapsulation hides internal details from users. Improves modularity.
    abstraction n. 抽象 Abstraction simplifies complex systems by modeling essentials. Key OOP concept.
    interface n. 接口 An interface defines methods without implementation. Used in design patterns.

    7.8 Common Programming Languages

    Word Part of Speech Chinese Meaning Example Sentence Note
    C n. C 语言 C is widely used for system and embedded programming. Procedural, fast, low-level.
    C++ n. C++ 语言 C++ supports object-oriented programming. Extension of C.
    Java n. Java 语言 Java is used for enterprise and Android development. Platform-independent.
    Python n. Python 语言 Python is known for its simplicity and readability. General-purpose language.
    JavaScript n. JavaScript 语言 JavaScript runs in browsers for web interactivity. Client-side scripting.
    PHP n. PHP 语言 PHP is widely used for dynamic web pages. Server-side scripting.
    Ruby n. Ruby 语言 Ruby emphasizes simplicity and productivity. Used in Ruby on Rails.
    Swift n. Swift 语言 Swift is Apple’s language for iOS development. Replaces Objective-C.
    Go (Golang) n. Go 语言 Go is efficient for building concurrent systems. Developed by Google.
    Rust n. Rust 语言 Rust offers memory safety without garbage collection. Systems programming language.

    7.9 Software Development Practices

    Word Part of Speech Chinese Meaning Example Sentence Note
    IDE (Integrated Development Environment) n. 集成开发环境 An IDE integrates editing, debugging, and compiling. e.g., VS Code, PyCharm.
    version control n. 版本控制 Git is a popular version control system. Tracks code changes.
    repository n. 仓库 Source code is stored in a Git repository. e.g., GitHub repository.
    commit v./n. 提交 Each commit saves a snapshot of the project. Basic VCS operation.
    branch n./v. 分支 Developers create branches for new features. Enables parallel development.
    merge v. 合并 Merge integrates changes from multiple branches. Resolves conflicts.
    build n./v. 构建 The build process compiles and links source code. Produces executables.
    test n./v. 测试 Unit tests ensure that code works correctly. Part of QA process.
    deploy v. 部署 The software is deployed to the production server. Delivery stage.
    documentation n. 文档 Good documentation explains how the software works. Important for maintenance.
