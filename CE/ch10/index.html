    Chapter 10: Emerging Technologies and Applications

    10.1 Artificial Intelligence (AI)

    Word Part of Speech Chinese Meaning Example Sentence Note
    artificial intelligence (AI) n. 人工智能 Artificial intelligence enables machines to simulate human thinking. Broad field of intelligent systems.
    machine learning (ML) n. 机器学习 Machine learning allows systems to learn from data. Subfield of AI.
    deep learning n. 深度学习 Deep learning uses neural networks for pattern recognition. A type of machine learning.
    neural network n. 神经网络 Neural networks mimic the structure of the human brain. Used for image and speech recognition.
    algorithm n. 算法 Machine learning models depend on algorithms to process data. Logical procedure for solving problems.
    training data n. 训练数据 Models are trained using large sets of labeled training data. Input for learning process.
    model n. 模型 The AI model predicts outcomes based on input data. Trained representation of data.
    inference n. 推理 The model performs inference to make new predictions. Applying learned knowledge.
    accuracy n. 准确率 Accuracy measures how well an AI model performs. Common evaluation metric.
    bias n. 偏差 Data bias can lead to unfair AI decisions. Ethical concern in AI.

    10.2 Machine Learning and Data Science

    Word Part of Speech Chinese Meaning Example Sentence Note
    dataset n. 数据集 The dataset contains millions of labeled images. Source of training data.
    feature n. 特征 Each feature represents an attribute of the data. Input variable.
    label n. 标签 Supervised learning uses labeled data for training. Output variable.
    supervised learning n. 监督学习 Supervised learning uses input-output pairs. Common ML type.
    unsupervised learning n. 无监督学习 Unsupervised learning finds hidden patterns without labels. Used in clustering.
    classification n. 分类 Classification separates data into predefined groups. e.g., spam or not spam.
    regression n. 回归 Regression predicts continuous values. e.g., price estimation.
    clustering n. 聚类 Clustering groups similar data points automatically. e.g., K-means.
    prediction n. 预测 The system makes predictions based on past data. Core goal of ML.
    evaluation n. 评估 Evaluation measures the model’s performance. Uses metrics like precision and recall.

    10.3 Cloud Computing

    Word Part of Speech Chinese Meaning Example Sentence Note
    cloud computing n. 云计算 Cloud computing provides computing resources over the Internet. Enables scalability and flexibility.
    virtualization n. 虚拟化 Virtualization allows multiple systems to run on one machine. Basis of cloud infrastructure.
    infrastructure n. 基础设施 Cloud infrastructure includes servers and storage. Physical foundation.
    scalability n. 可扩展性 Cloud systems support high scalability for growing workloads. Key advantage of cloud.
    elasticity n. 弹性 Elasticity lets resources scale up or down automatically. Dynamic allocation.
    on-demand adj. 按需的 Cloud services are available on-demand. Pay-as-you-go model.
    public cloud n. 公有云 Public clouds are shared among multiple users. e.g., AWS, Azure.
    private cloud n. 私有云 Private clouds are managed by individual organizations. Internal use only.
    hybrid cloud n. 混合云 A hybrid cloud combines public and private clouds. Balances control and flexibility.
    multi-cloud n. 多云环境 Companies use multi-cloud strategies to avoid dependency. Uses multiple providers.

    10.4 Internet of Things (IoT)

    Word Part of Speech Chinese Meaning Example Sentence Note
    IoT (Internet of Things) n. 物联网 The Internet of Things connects physical devices to the Internet. Expands connectivity to everyday objects.
    sensor n. 传感器 Sensors collect environmental data like temperature and humidity. Key component of IoT.
    actuator n. 执行器 Actuators perform actions based on IoT commands. Converts signal to motion.
    smart device n. 智能设备 Smart devices can communicate with each other automatically. e.g., smart TVs, thermostats.
    embedded system n. 嵌入式系统 IoT devices often use small embedded systems. Runs on microcontrollers.
    connectivity n. 连接性 IoT relies on strong wireless connectivity. e.g., Wi-Fi, Bluetooth, 5G.
    automation n. 自动化 Home automation systems adjust lighting and temperature. Common IoT application.
    edge computing n. 边缘计算 Edge computing processes data near IoT devices. Reduces latency.
    gateway n. 网关 The IoT gateway connects local devices to the cloud. Communication bridge.
    real-time monitoring n. 实时监控 IoT enables real-time monitoring of industrial systems. Important for safety and control.

    10.5 Big Data and Analytics

    Word Part of Speech Chinese Meaning Example Sentence Note
    big data n. 大数据 Big data refers to massive and complex datasets. Characterized by volume, velocity, variety.
    analytics n. 分析 Data analytics turns raw data into useful insights. Supports decision-making.
    data mining n. 数据挖掘 Data mining discovers hidden patterns in large datasets. Related to AI and statistics.
    data visualization n. 数据可视化 Data visualization helps users understand information easily. Graphical presentation.
    dashboard n. 仪表板 The dashboard displays key performance metrics. Interactive visualization.
    real-time processing n. 实时处理 Real-time data processing enables instant feedback. e.g., stock trading.
    data warehouse n. 数据仓库 A data warehouse stores historical business data. Optimized for queries and analysis.
    distributed computing n. 分布式计算 Distributed computing splits tasks across multiple computers. e.g., Hadoop framework.
    parallel processing n. 并行处理 Parallel processing increases speed through simultaneous execution. Used in big data systems.
    scalability n. 可扩展性 Big data systems must support high scalability. Essential for handling growth.

    10.6 Blockchain Technology

    Word Part of Speech Chinese Meaning Example Sentence Note
    blockchain n. 区块链 Blockchain is a distributed ledger that records transactions. Core of cryptocurrencies.
    transaction n. 交易 Each blockchain transaction is stored securely in a block. Immutable record.
    ledger n. 账本 The distributed ledger is shared across all participants. Public or private.
    decentralization n. 去中心化 Blockchain eliminates the need for a central authority. Improves transparency.
    node n. 节点 Each node maintains a copy of the blockchain. Network participant.
    consensus n. 共识 Consensus ensures all nodes agree on transactions. e.g., Proof of Work, Proof of Stake.
    smart contract n. 智能合约 Smart contracts execute automatically when conditions are met. Used in Ethereum.
    cryptocurrency n. 加密货币 Bitcoin is the first widely adopted cryptocurrency. Digital currency on blockchain.
    token n. 代币 Tokens represent digital assets on blockchain platforms. e.g., ERC-20 tokens.
    mining n. 挖矿 Mining verifies and adds new transactions to the blockchain. Requires computational power.

    10.7 Virtual Reality (VR) and Augmented Reality (AR)

    Word Part of Speech Chinese Meaning Example Sentence Note
    virtual reality (VR) n. 虚拟现实 VR immerses users in a fully simulated environment. Requires special headsets.
    augmented reality (AR) n. 增强现实 AR overlays digital information onto the real world. e.g., AR games and navigation.
    mixed reality (MR) n. 混合现实 MR combines both virtual and real-world elements. Advanced hybrid of VR and AR.
    headset n. 头戴显示设备 VR headsets display 3D environments. e.g., Meta Quest, HTC Vive.
    immersive adj. 沉浸式的 Immersive experiences engage multiple senses. Related to VR applications.
    3D modeling n. 三维建模 3D modeling is used to create virtual environments. Foundation of VR/AR design.
    simulation n. 模拟 Simulations are used for training and entertainment. Virtual representation of real-world systems.
    gesture control n. 手势控制 Gesture control allows users to interact naturally in AR. Used in HoloLens, etc.
    spatial computing n. 空间计算 Spatial computing maps and understands physical space. Emerging AR concept.
    interactivity n. 交互性 VR applications focus on realism and interactivity. Enhances user engagement.

    10.8 Robotics and Automation

    Word Part of Speech Chinese Meaning Example Sentence Note
    robotics n. 机器人学 Robotics combines mechanics, electronics, and computing. Interdisciplinary field.
    robot n. 机器人 Robots can perform repetitive or dangerous tasks. Controlled by software.
    automation n. 自动化 Automation reduces human intervention in manufacturing. Improves efficiency.
    autonomous adj. 自主的 Autonomous robots can operate without human control. Used in vehicles and drones.
    sensor n. 传感器 Robots use sensors to detect their environment. Provides input data.
    actuator n. 执行器 Actuators move the robot’s limbs or tools. Converts energy to motion.
    control system n. 控制系统 The control system manages robot actions. Uses feedback loops.
    AI integration n. 人工智能集成 AI integration makes robots smarter and adaptive. Enables decision-making.
    industrial robot n. 工业机器人 Industrial robots are common in car manufacturing. High-precision automation.
    drone n. 无人机 Drones can deliver packages or capture aerial photos. Autonomous flying robots.

    10.9 Future Trends in Computing

    Word Part of Speech Chinese Meaning Example Sentence Note
    quantum computing n. 量子计算 Quantum computing uses quantum bits to process data. Promises exponential speedup.
    nanotechnology n. 纳米技术 Nanotechnology enables microscopic computing components. Basis for future chips.
    bioinformatics n. 生物信息学 Bioinformatics applies computing to biological data. Combines biology and data science.
    edge AI n. 边缘人工智能 Edge AI runs models on local devices for faster response. Combines AI with edge computing.
    autonomous vehicle n. 自动驾驶车辆 Autonomous vehicles rely on AI and sensors. Self-driving cars.
    smart city n. 智慧城市 Smart cities use IoT for efficient urban management. Integrates multiple technologies.
    digital twin n. 数字孪生 Digital twins simulate physical systems in real time. Used in engineering and IoT.
    sustainability n. 可持续性 Technology innovation focuses on sustainability goals. Eco-friendly computing.
    human-computer interaction (HCI) n. 人机交互 HCI studies how people interact with technology. Crucial for UX design.
    innovation n. 创新 Continuous innovation drives technological progress. Central to computing evolution.
