    Chapter 9: The Internet and Web Technologies

    9.1 Introduction to the Internet

    Word Part of Speech Chinese Meaning Example Sentence Note
    Internet n. 互联网 The Internet connects millions of computers around the world. Global communication network.
    World Wide Web (WWW) n. 万维网 The World Wide Web is a system of interlinked web pages. Subset of the Internet.
    web n. 网络 The web allows users to access online information easily. Often refers to websites collectively.
    online adj./adv. 在线的 Online services are available 24 hours a day. Opposite of offline.
    website n. 网站 The company launched a new website for its products. Collection of related web pages.
    webpage n. 网页 Each webpage is written in HTML and displayed in a browser. Basic web unit.
    hyperlink n. 超链接 Click the hyperlink to open another page. Connects documents together.
    domain name n. 域名 “example.com” is an Internet domain name. Translated by DNS.
    URL (Uniform Resource Locator) n. 统一资源定位符 A URL specifies the address of a resource on the web. e.g., https://www.example.com
    browser n. 浏览器 Chrome and Firefox are popular web browsers. Client software for the web.

    9.2 Internet Infrastructure

    Word Part of Speech Chinese Meaning Example Sentence Note
    server n. 服务器 Web servers store and deliver web content. Responds to client requests.
    client n. 客户端 A client requests information from a server. e.g., web browser.
    host n. 主机 Every device on a network is called a host. Identified by IP address.
    IP address n. IP 地址 Every Internet host has a unique IP address. IPv4 or IPv6.
    DNS (Domain Name System) n. 域名系统 DNS translates domain names into IP addresses. Internet “phone book.”
    TCP/IP n. 传输控制协议/网际协议 TCP/IP is the fundamental protocol suite of the Internet. Basis of Internet communication.
    packet n. 数据包 Data are sent across the Internet in packets. Unit of data transmission.
    router n. 路由器 Routers direct data packets to their destinations. Network device.
    ISP (Internet Service Provider) n. 互联网服务提供商 You need an ISP to connect to the Internet. e.g., China Telecom, AT&T.
    bandwidth n. 带宽 Bandwidth determines how much data can be transmitted. Measured in bits per second.

    9.3 Web Architecture

    Word Part of Speech Chinese Meaning Example Sentence Note
    web server n. 网络服务器 Apache is a popular open-source web server. Hosts websites.
    web client n. 网络客户端 A browser acts as a web client. Requests resources.
    HTTP (Hypertext Transfer Protocol) n. 超文本传输协议 HTTP is used for transferring web data. Application layer protocol.
    HTTPS (Hypertext Transfer Protocol Secure) n. 安全超文本传输协议 HTTPS encrypts data between client and server. Secure version of HTTP.
    request n. 请求 The browser sends a request to the web server. Client action.
    response n. 响应 The server sends a response to the browser. Server’s reply.
    session n. 会话 A web session stores user activity temporarily. Maintains continuity.
    cookie n. Cookie 文件 Cookies save user preferences on the client side. Small text files used by browsers.
    cache n. 缓存 Browser cache stores web data locally for faster access. Improves performance.
    API (Application Programming Interface) n. 应用程序接口 APIs allow web applications to exchange data. e.g., REST API.

    9.4 Web Development Languages

    Word Part of Speech Chinese Meaning Example Sentence Note
    HTML (HyperText Markup Language) n. 超文本标记语言 HTML defines the structure of web pages. Markup language.
    CSS (Cascading Style Sheets) n. 层叠样式表 CSS controls the appearance of web pages. For styling and layout.
    JavaScript n. JavaScript 语言 JavaScript adds interactivity to web pages. Client-side scripting.
    PHP n. PHP 语言 PHP is used for creating dynamic web pages. Server-side scripting.
    SQL n. 结构化查询语言 SQL is used for database communication. Used in back-end systems.
    JSON (JavaScript Object Notation) n. JavaScript 对象表示法 JSON is a lightweight data format for APIs. Used for data exchange.
    XML (Extensible Markup Language) n. 可扩展标记语言 XML structures data in a human- and machine-readable form. Often used for configuration.
    framework n. 框架 React and Django are popular web frameworks. Provide reusable components.
    front-end n. 前端 The front-end handles the user interface. Runs in the browser.
    back-end n. 后端 The back-end manages server-side logic and databases. Runs on the server.

    9.5 Web Design and User Experience

    Word Part of Speech Chinese Meaning Example Sentence Note
    layout n. 布局 The layout determines how elements are arranged on a page. Visual structure.
    navigation n. 导航 Good navigation improves website usability. Menus and links.
    hyperlink n. 超链接 Hyperlinks allow users to jump between pages. Connects resources.
    menu n. 菜单 The top menu provides access to main sections. GUI element.
    responsive design n. 响应式设计 Responsive design adapts to different screen sizes. Important for mobile web.
    accessibility n. 可访问性 Accessibility ensures that websites are usable by everyone. Includes screen reader support.
    usability n. 可用性 Usability testing measures user satisfaction. Human-centered design.
    interface n. 界面 The interface should be clear and intuitive. User-facing part of the system.
    theme n. 主题 The website theme defines colors and typography. Visual identity.
    template n. 模板 Templates save time in web design. Predefined layout structure.

    9.6 Internet Services and Applications

    Word Part of Speech Chinese Meaning Example Sentence Note
    email n. 电子邮件 Email remains a common form of online communication. Internet-based messaging.
    instant messaging n. 即时通讯 Instant messaging allows real-time text exchange. e.g., WhatsApp, Telegram.
    cloud computing n. 云计算 Cloud computing provides scalable online resources. Includes IaaS, PaaS, SaaS.
    streaming n. 流媒体 Streaming allows watching videos without full download. e.g., YouTube, Netflix.
    online storage n. 在线存储 Services like Google Drive offer online file storage. Also called cloud storage.
    search engine n. 搜索引擎 Google is the world’s leading search engine. Finds web content.
    social media n. 社交媒体 Social media platforms connect people worldwide. e.g., Twitter, Instagram.
    e-commerce n. 电子商务 E-commerce enables online shopping and transactions. e.g., Amazon, Taobao.
    forum n. 论坛 Users share opinions in online forums. Discussion platform.
    blog n. 博客 Many professionals write blogs to share knowledge. Online journal or publication.

    9.7 Cloud and Web Services

    Word Part of Speech Chinese Meaning Example Sentence Note
    cloud n. 云 Data stored in the cloud can be accessed anywhere. Internet-based storage.
    SaaS (Software as a Service) n. 软件即服务 SaaS delivers software via the Internet. e.g., Google Docs.
    PaaS (Platform as a Service) n. 平台即服务 Developers use PaaS for application deployment. Provides tools and environments.
    IaaS (Infrastructure as a Service) n. 基础设施即服务 IaaS provides virtualized hardware resources. e.g., AWS EC2.
    virtualization n. 虚拟化 Virtualization enables multiple systems on one machine. Core of cloud computing.
    container n. 容器 Containers package applications with all dependencies. e.g., Docker.
    scalability n. 可扩展性 Cloud systems provide high scalability. Easily handle growth.
    API gateway n. API 网关 The API gateway manages access to multiple web services. Controls communication between clients and APIs.
    CDN (Content Delivery Network) n. 内容分发网络 CDNs deliver web content faster by caching it worldwide. Improves website performance.
    uptime n. 正常运行时间 Cloud providers guarantee 99.9% uptime. Reliability metric.

    9.8 Web Security and Privacy

    Word Part of Speech Chinese Meaning Example Sentence Note
    HTTPS n. 安全超文本传输协议 HTTPS ensures secure data exchange between browsers and servers. Encrypts web traffic.
    SSL/TLS n. 安全套接层/传输层安全协议 SSL/TLS protocols provide web encryption. Used by HTTPS.
    certificate n. 证书 Websites use digital certificates to verify identity. Issued by certificate authorities (CA).
    authentication n. 身份验证 Two-factor authentication improves login security. Prevents unauthorized access.
    authorization n. 授权 Authorization defines what users can do on a site. Role-based access control.
    cookie n. Cookie 文件 Cookies may store personal data for login sessions. Privacy concern.
    privacy policy n. 隐私政策 The privacy policy explains how data are collected and used. Required by law in many regions.
    malware n. 恶意软件 Malware can be distributed through insecure websites. Includes trojans and spyware.
    phishing n. 网络钓鱼 Phishing websites imitate legitimate ones to steal passwords. Major web security risk.
    firewall n. 防火墙 Web servers use firewalls to filter malicious requests. Part of web defense.

    9.9 Emerging Web Technologies

    Word Part of Speech Chinese Meaning Example Sentence Note
    Web 2.0 n. Web 2.0 技术 Web 2.0 emphasizes user-generated content and interactivity. Social web era.
    Web 3.0 n. Web 3.0 技术 Web 3.0 integrates blockchain and decentralized data. Semantic and decentralized web.
    semantic web n. 语义网 The semantic web helps computers understand web data. Machine-readable Internet.
    progressive web app (PWA) n. 渐进式网络应用 PWAs work offline and behave like native apps. Modern web application model.
    artificial intelligence (AI) n. 人工智能 AI enhances personalization in web services. Used in recommendation systems.
    machine learning n. 机器学习 Machine learning improves search and ad targeting. Subfield of AI.
    blockchain n. 区块链 Blockchain enables secure, decentralized web transactions. Foundation of Web3.
    virtual reality (VR) n. 虚拟现实 VR websites provide immersive experiences. 3D interaction.
    augmented reality (AR) n. 增强现实 AR overlays digital data on the real world. Used in mobile web applications.
    IoT (Internet of Things) n. 物联网 IoT integrates web access into everyday devices. Smart homes, wearable tech.
