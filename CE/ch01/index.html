    Chapter 1: Computer Basics

    1.1 The Concept of a Computer

    Word Part of Speech Chinese Meaning Example Sentence Note
    computer n. 计算机 A computer is an electronic device that processes data and produces information. Core term; derived from “compute”.
    electronic adj. 电子的 A computer is an electronic machine that works with electricity. Related to electricity.
    device n. 设备，装置 A smartphone is a portable computing device. Often used with input/output.
    system n. 系统 A computer system consists of hardware and software. General concept; also operating system.
    component n. 组件，部件 The CPU is an important component of a computer. Hardware or logical part.
    function n. 功能 The main function of a computer is data processing. Also a programming term.
    process v./n. 处理，过程 Computers process data to produce information. “Processing” = 执行计算任务。
    data n. 数据 Data are raw facts before processing. Plural in formal usage.
    information n. 信息 Information is organized and meaningful data. The goal of computing.
    user n. 用户 The user interacts with the computer through a screen and keyboard. “End user” = 最终用户。

    1.2 Basic Components of a Computer

    Word Part of Speech Chinese Meaning Example Sentence Note
    hardware n. 硬件 Hardware includes the physical parts of a computer. Tangible elements.
    software n. 软件 Software gives instructions to the hardware. Intangible; programs.
    peripheral n. 外设 Printers and scanners are peripheral devices. External devices.
    input device n. 输入设备 A keyboard is a common input device. For entering data.
    output device n. 输出设备 The monitor is an output device. For displaying results.
    storage n. 存储 Storage devices keep data permanently. Long-term memory.
    CPU (Central Processing Unit) n. 中央处理器 The CPU executes instructions from programs. “The brain of the computer.”
    memory n. 内存，存储器 Data are stored in memory while being processed. Usually RAM.
    bus n. 总线 The system bus connects the CPU and memory. Communication channel.
    main unit n. 主机 The main unit contains the CPU, memory, and motherboard. Also called “system unit.”

    1.3 The Working Principle (Input–Process–Output Cycle)

    Word Part of Speech Chinese Meaning Example Sentence Note
    input n./v. 输入 We input data through the keyboard. Step 1 of I–P–O cycle.
    processing n. 处理 Processing transforms input data into meaningful results. Step 2.
    output n./v. 输出 The monitor shows the output of the program. Step 3.
    cycle n. 循环 The input–process–output cycle repeats continuously. Logical sequence.
    instruction n. 指令 The CPU follows instructions stored in memory. Basic execution unit.
    execute v. 执行 The processor executes one instruction at a time. Synonym: run.
    operation n. 操作，运算 The ALU performs arithmetic operations. Can be math or control operations.
    control v./n. 控制 The control unit directs all operations in the CPU. “Control flow” in programming.
    result n. 结果 The result of the computation is displayed on the screen. Outcome of processing.

    1.4 Data and Number Systems

    Word Part of Speech Chinese Meaning Example Sentence Note
    bit n. 位 A bit is the smallest unit of data. Binary digit (0 or 1).
    byte n. 字节 A byte consists of eight bits. Common storage unit.
    binary adj./n. 二进制的；二进制 Data are represented in binary form. Base 2 system.
    decimal adj./n. 十进制的；小数 Humans usually count in decimal numbers. Base 10 system.
    hexadecimal adj./n. 十六进制的 Hexadecimal numbers are used in programming. Base 16 system.
    code n./v. 代码；编码 ASCII code represents characters using binary values. Also “to code” = 编程。
    character n. 字符 Each character is stored as a code value. Letters, digits, symbols.
    data representation n. 数据表示 Binary digits are used for data representation. Common topic in exams.
    convert v. 转换 Computers convert data between formats. “Convert A into B.”

    1.5 Types of Computers

    Word Part of Speech Chinese Meaning Example Sentence Note
    desktop computer n. 台式计算机 Desktop computers are used in offices. Non-portable PC.
    laptop n. 笔记本电脑 Laptops are light and portable. Portable computer.
    tablet n. 平板电脑 Tablets use touch screens for input. Touch-based.
    smartphone n. 智能手机 A smartphone is a type of handheld computer. Mobile device.
    workstation n. 工作站 Designers use workstations for 3D modeling. High-end PC.
    mainframe n. 大型机 Mainframes handle large-scale business data. Enterprise-level systems.
    supercomputer n. 超级计算机 Supercomputers perform trillions of calculations per second. High-performance computing.
    embedded system n. 嵌入式系统 Embedded systems control devices like cars and machines. Specialized function system.
    server n. 服务器 A server provides services to other computers on a network. Supports clients.
    client n. 客户端 The client sends requests to the server. Client–server model.

    1.6 Computer Performance and Reliability

    Word Part of Speech Chinese Meaning Example Sentence Note
    speed n. 速度 CPU speed is measured in gigahertz. Related to performance.
    performance n. 性能 The computer’s performance depends on memory and CPU. Measured by speed and efficiency.
    efficiency n. 效率 Modern processors work with higher efficiency. Time and resource use.
    reliability n. 可靠性 Mainframes are designed for high reliability. Related to uptime.
    capacity n. 容量 Storage capacity is measured in gigabytes. Memory or disk size.
    upgrade v./n. 升级 You can upgrade your RAM to improve performance. Hardware or software upgrade.
    maintain v. 维护 Technicians maintain the system regularly. Related noun: maintenance.
    crash v./n. 崩溃 The system crashed due to a power failure. Unexpected failure.
    backup n./v. 备份 Always make a backup before installing new software. Data protection.
    restore v. 恢复 You can restore data from the backup file. Opposite of delete.

    1.7 History and Generations of Computers

    Word Part of Speech Chinese Meaning Example Sentence Note
    generation n. 代，世代 Computers are classified into five generations. 1st–5th generation.
    vacuum tube n. 电子管 The first generation used vacuum tubes. 1940s–1950s technology.
    transistor n. 晶体管 The second generation replaced tubes with transistors. Smaller and faster.
    integrated circuit n. 集成电路 The third generation used integrated circuits. IC chips.
    microprocessor n. 微处理器 The microprocessor made personal computers possible. Key to 4th generation.
    artificial intelligence n. 人工智能 The fifth generation focuses on artificial intelligence. AI and expert systems.
    evolution n. 演变 The evolution of computers shows rapid progress. Continuous improvement.
