## 6.1 Introduction to Data

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|data|n.|数据|Data are raw facts collected from observations.|Plural in formal writing; often singular in computing.|
|information|n.|信息|Information is organized and meaningful data.|Data + context = information.|
|record|n.|记录|Each record contains information about one entity.|Row in a database table.|
|field|n.|字段|A field stores a single piece of data, such as a name or age.|Column in a table.|
|dataset|n.|数据集|The researcher analyzed a large dataset of customer transactions.|Collection of data items.|
|metadata|n.|元数据|Metadata describes the structure and meaning of data.|“Data about data.”|
|data type|n.|数据类型|Common data types include integer, float, and string.|Defines how data are stored.|
|value|n.|值|Each field in a record has a specific value.|Data item.|
|variable|n.|变量|A variable holds data that can change during program execution.|Common in programming and data analysis.|
|data processing|n.|数据处理|Computers perform data processing automatically.|Turning raw data into useful info.|

## 6.3 Introduction to Databases

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|database|n.|数据库|A database stores and manages large amounts of data.|Centralized data storage.|
|DBMS (Database Management System)|n.|数据库管理系统|A DBMS allows users to create and manage databases.|Examples: MySQL, Oracle.|
|relational database|n.|关系型数据库|A relational database organizes data into tables.|Uses relationships between tables.|
|non-relational database|n.|非关系型数据库|NoSQL databases store unstructured data.|e.g., MongoDB.|
|SQL (Structured Query Language)|n.|结构化查询语言|SQL is used to query and manage relational databases.|Standard database language.|
|query|n./v.|查询|You can use SQL queries to find specific data.|Database request.|
|schema|n.|模式|The database schema defines the structure of data.|Blueprint of the database.|
|relationship|n.|关系|Relationships link tables through keys.|One-to-one, one-to-many, etc.|
|primary key|n.|主键|The primary key uniquely identifies each record.|Must be unique and non-null.|
|foreign key|n.|外键|Foreign keys link related tables.|Enforces referential integrity.|

## 6.4 Database Models and Architecture

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|data model|n.|数据模型|The relational data model is widely used.|Conceptual framework for organizing data.|
|hierarchical model|n.|层次模型|The hierarchical model organizes data in a tree structure.|Used in early databases.|
|network model|n.|网状模型|The network model allows multiple relationships.|Predecessor to relational model.|
|relational model|n.|关系模型|The relational model represents data as tables.|Introduced by E. F. Codd.|
|object-oriented model|n.|面向对象模型|Object-oriented databases store objects instead of tables.|Integrates with OOP.|
|entity|n.|实体|Each row in a table represents an entity.|Something identifiable.|
|attribute|n.|属性|Attributes describe the properties of an entity.|Columns in a table.|
|normalization|n.|规范化|Normalization reduces redundancy in a database.|Improves consistency.|
|redundancy|n.|冗余|Data redundancy wastes storage space.|Avoided through normalization.|
|integrity|n.|完整性|Data integrity ensures accuracy and consistency.|Maintained by constraints.|

## 6.5 SQL Language Basics

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|SQL (Structured Query Language)|n.|结构化查询语言|SQL allows users to manipulate data easily.|Standard for relational DB.|
|query|n./v.|查询|You can write a query to select certain rows.|SQL command.|
|SELECT|v.|选择（SQL命令）|The SELECT statement retrieves data from a table.|Basic SQL keyword.|
|INSERT|v.|插入|Use INSERT to add new records.|Adds data.|
|UPDATE|v.|更新|UPDATE changes existing data in a table.|Modifies records.|
|DELETE|v.|删除|DELETE removes records from a table.|Opposite of INSERT.|
|WHERE|conj.|条件从句（SQL）|WHERE filters records based on conditions.|Used with SELECT/UPDATE.|
|ORDER BY|phr.|排序|ORDER BY sorts results in ascending or descending order.|Sorting clause.|
|GROUP BY|phr.|分组|GROUP BY groups data by one or more columns.|Used for aggregation.|
|JOIN|v.|连接|JOIN combines rows from two or more tables.|Inner, outer, left, right joins.|

## 6.6 Database Operations and Management

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|transaction|n.|事务|A transaction is a logical unit of work in a database.|Ensures data consistency.|
|commit|v.|提交|Changes are saved to the database when you commit a transaction.|Confirms changes.|
|rollback|v.|回滚|Rollback cancels uncommitted changes.|Restores previous state.|
|concurrency|n.|并发|The DBMS handles multiple transactions concurrently.|Multi-user environment.|
|lock|n./v.|锁|Locks prevent conflicts during concurrent updates.|Ensures data integrity.|
|backup|n./v.|备份|Always back up the database regularly.|Prevents data loss.|
|restore|v.|恢复|The database can be restored from a backup file.|Recovery process.|
|index|n.|索引|An index speeds up data retrieval.|Similar to a book index.|
|constraint|n.|约束|Constraints ensure data validity.|e.g., NOT NULL, UNIQUE.|
|privilege|n.|权限|Database privileges control user access.|Managed by DBMS.|
