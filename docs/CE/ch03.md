
# Chapter 3: Computer Software

---

## 3.1 Overview of Software

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|software|n.|软件|Software tells the computer what to do.|Opposite of hardware.|
|program|n.|程序|A program is a set of instructions that performs a task.|Written by programmers.|
|application|n.|应用程序|Word processors and browsers are common applications.|Also called _app_.|
|system software|n.|系统软件|The operating system is a type of system software.|Controls hardware.|
|application software|n.|应用软件|Application software helps users perform specific tasks.|e.g., Office, Photoshop.|
|utility|n.|实用程序|Antivirus software is a common utility.|System maintenance tools.|
|driver|n.|驱动程序|You must install the printer driver before printing.|Connects hardware and OS.|
|update|n./v.|更新|The software update fixes several bugs.|Usually downloaded online.|
|upgrade|n./v.|升级|The new version offers more features.|May require reinstallation.|
|version|n.|版本|You are using version 2.1 of the software.|Labeled with numbers.|

---

## 3.2 Operating Systems

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|operating system (OS)|n.|操作系统|Windows, macOS, and Linux are popular operating systems.|Core system software.|
|kernel|n.|内核|The kernel manages hardware and system resources.|Heart of the OS.|
|interface|n.|界面|The graphical user interface makes computers easy to use.|GUI or CLI.|
|GUI (Graphical User Interface)|n.|图形用户界面|GUI allows users to click icons and menus.|Used in modern OS.|
|CLI (Command Line Interface)|n.|命令行界面|Linux supports both GUI and CLI.|Text-based interface.|
|multitasking|n.|多任务处理|Modern operating systems support multitasking.|Running multiple programs at once.|
|file system|n.|文件系统|The file system organizes data on storage devices.|e.g., FAT32, NTFS, ext4.|
|process|n.|进程|Each running program is a process.|OS allocates resources to processes.|
|thread|n.|线程|Threads are lightweight units within a process.|Used for parallel execution.|
|boot|v./n.|启动|The OS loads during the boot process.|Also called “startup.”|

## 3.3 Types of Software

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|open-source software|n.|开源软件|Linux is an open-source operating system.|Free to modify and distribute.|
|proprietary software|n.|专有软件|Microsoft Office is proprietary software.|Owned by a company.|
|freeware|n.|免费软件|VLC Media Player is freeware.|Free but not open-source.|
|shareware|n.|共享软件|Shareware can be used for free during a trial period.|Requires payment later.|
|commercial software|n.|商业软件|Photoshop is commercial software.|Sold under license.|
|demo version|n.|演示版|The demo version has limited functions.|Used for trial or preview.|
|patch|n.|补丁|The latest patch fixes a security flaw.|Software correction.|
|license|n.|许可证|You need a license to use commercial software.|Legal permission.|
|activation|n.|激活|Internet activation is required to use the product.|Confirms license validity.|
|piracy|n.|软件盗版|Software piracy is illegal and unethical.|Unauthorized copying.|

## 3.4 Programming and Development Software

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|programming language|n.|程序设计语言|Python is an easy-to-learn programming language.|Used to write programs.|
|compiler|n.|编译器|The compiler translates source code into machine code.|e.g., GCC, Clang.|
|interpreter|n.|解释器|The interpreter executes code line by line.|e.g., Python interpreter.|
|assembler|n.|汇编器|The assembler converts assembly code to machine code.|Used in low-level programming.|
|debugger|n.|调试器|The debugger helps programmers find and fix errors.|Debugging tool.|
|integrated development environment (IDE)|n.|集成开发环境|PyCharm is a popular IDE for Python.|Combines editor, compiler, debugger.|
|code editor|n.|代码编辑器|VS Code is a lightweight code editor.|Text-based programming tool.|
|source code|n.|源代码|Programmers write source code in high-level languages.|Human-readable.|
|machine code|n.|机器代码|The CPU executes machine code directly.|Binary form of instructions.|
|script|n.|脚本|A shell script automates system tasks.|Common in Linux environments.|

## 3.5 Software Installation and Management

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|install|v.|安装|You must install the software before use.|Opposite: _uninstall_.|
|uninstall|v.|卸载|Please uninstall unused programs.|Removes from system.|
|setup|n./v.|安装程序；设置|Follow the setup wizard to complete installation.|Common installer name.|
|configuration|n.|配置|The configuration file contains user preferences.|Often _.cfg_ files.|
|compatibility|n.|兼容性|The new software is compatible with Windows 11.|Opposite: _incompatibility_.|
|update|v./n.|更新|Automatic updates improve security.|May download patches.|
|rollback|v.|回滚|You can roll back to the previous version if needed.|Undo an update.|
|reinstall|v.|重新安装|Reinstall the OS to fix system problems.|Clean setup.|
|package manager|n.|软件包管理器|Linux uses package managers like apt and yum.|Tool for installation and updates.|
|shortcut|n.|快捷方式|A desktop shortcut provides quick access to the program.|Icon link.|

|---|---|---|---|---|

|performance|n.|性能|Software performance depends on hardware and code.|Related to speed.|
|stability|n.|稳定性|The new update improves system stability.|Reduces crashes.|
