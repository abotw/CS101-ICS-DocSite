# Chapter 8: Computer Security

---

## 8.1 Introduction to Computer Security

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|security|n.|安全|Computer security protects systems and data from threats.|Broad term; includes physical and digital safety.|
|cybersecurity|n.|网络安全|Cybersecurity focuses on defending computers and networks.|Field of IT protection.|
|threat|n.|威胁|A security threat may come from hackers or malware.|Potential source of harm.|
|vulnerability|n.|漏洞|Software vulnerabilities can be exploited by attackers.|Weakness in system security.|
|attack|n./v.|攻击|The server suffered a denial-of-service attack.|Malicious action against systems.|
|risk|n.|风险|Organizations must assess security risks regularly.|Combination of threat and vulnerability.|
|protection|n.|保护|Encryption provides protection for sensitive data.|Safeguarding data and systems.|
|defense|n.|防御|Layered defense is more effective than single-layer security.|Also used metaphorically.|
|policy|n.|策略|A security policy defines acceptable system use.|Management-level control.|
|compliance|n.|合规|Companies must ensure compliance with data protection laws.|e.g., GDPR, ISO standards.|

## 8.2 Types of Threats and Attacks

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|malware|n.|恶意软件|Malware includes viruses, worms, and spyware.|Malicious software.|
|virus|n.|病毒|A virus attaches itself to other programs and spreads.|Requires host file.|
|worm|n.|蠕虫|A worm can replicate itself across networks.|Self-propagating.|
|trojan horse|n.|木马|A trojan horse disguises itself as a legitimate program.|Delivers hidden malware.|
|spyware|n.|间谍软件|Spyware secretly collects user information.|Monitors user activity.|
|adware|n.|广告软件|Adware displays unwanted ads on your computer.|Often bundled with free software.|
|ransomware|n.|勒索软件|Ransomware encrypts files and demands payment.|Major modern threat.|
|phishing|n.|网络钓鱼|Phishing emails trick users into revealing passwords.|Social engineering attack.|
|social engineering|n.|社会工程学|Social engineering manipulates people to reveal confidential data.|Exploits human trust.|
|spoofing|n.|欺骗|Email spoofing disguises the sender’s identity.|Fake identity attack.|

## 8.3 Authentication and Access Control

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|authentication|n.|身份验证|Authentication verifies the identity of a user.|e.g., password, biometrics.|
|authorization|n.|授权|Authorization determines which resources a user can access.|Follows authentication.|
|access control|n.|访问控制|Access control prevents unauthorized actions.|Security mechanism.|
|password|n.|密码|Choose strong passwords with mixed characters.|Common authentication method.|
|PIN (Personal Identification Number)|n.|个人识别码|Enter your PIN to unlock the device.|Numeric password.|
|biometrics|n.|生物识别技术|Biometrics include fingerprint and facial recognition.|Used for secure authentication.|
|multi-factor authentication (MFA)|n.|多因素认证|MFA combines passwords with additional verification.|e.g., SMS code + fingerprint.|
|login|v./n.|登录|You must log in before accessing your account.|User access process.|
|logout|v./n.|登出|Always log out from public computers.|Ends session securely.|
|session|n.|会话|Sessions are terminated after inactivity.|Temporary user connection.|

## 8.4 Encryption and Cryptography

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|encryption|n.|加密|Encryption converts data into unreadable form.|Protects data confidentiality.|
|decrypt|v.|解密|Only authorized users can decrypt the message.|Reverse of encryption.|
|cryptography|n.|密码学|Cryptography is the science of securing communication.|Includes encryption, hashing, and signatures.|
|cipher|n.|密码；加密算法|AES is a popular symmetric cipher.|Encryption method.|
|key|n.|密钥|Encryption keys must be kept secret.|Used to encrypt/decrypt data.|
|symmetric encryption|n.|对称加密|Symmetric encryption uses the same key for both encryption and decryption.|e.g., AES, DES.|
|asymmetric encryption|n.|非对称加密|Asymmetric encryption uses public and private keys.|e.g., RSA.|
|hash function|n.|哈希函数|A hash function produces a fixed-size output.|Used for data integrity.|
|digital signature|n.|数字签名|Digital signatures verify the sender’s identity.|Based on public-key cryptography.|
|certificate|n.|证书|Websites use digital certificates to prove authenticity.|e.g., SSL/TLS certificates.|

## 8.5 Network Security

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|firewall|n.|防火墙|The firewall blocks unauthorized access to the network.|Hardware or software-based.|
|intrusion detection system (IDS)|n.|入侵检测系统|An IDS monitors suspicious network traffic.|Detects potential attacks.|
|intrusion prevention system (IPS)|n.|入侵防御系统|The IPS can automatically block harmful traffic.|Extends IDS functionality.|
|VPN (Virtual Private Network)|n.|虚拟专用网络|A VPN encrypts your Internet connection.|Secures communication channels.|
|proxy server|n.|代理服务器|Proxy servers hide the user’s real IP address.|Provides anonymity and filtering.|
|packet filtering|n.|数据包过滤|Packet filtering controls inbound and outbound data packets.|Firewall mechanism.|
|port scanning|n.|端口扫描|Port scanning checks for open network ports.|Used by admins and attackers alike.|
|intrusion|n.|入侵|The IDS detected a possible intrusion attempt.|Unauthorized access.|
|sniffing|n.|嗅探|Packet sniffing captures network data for analysis.|Can be used legally or maliciously.|
|honeypot|n.|蜜罐|Honeypots are traps set to lure hackers.|Used in security research.|
