
# Chapter 4: Operating Systems

---

## 4.1 Introduction to Operating Systems

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|operating system (OS)|n.|操作系统|The operating system manages both hardware and software resources.|Core system software.|
|kernel|n.|内核|The kernel controls low-level system operations.|Central part of the OS.|
|shell|n.|外壳；命令解释器|The shell provides an interface between the user and the OS.|Command-line environment.|
|interface|n.|界面|The OS offers a user interface for interaction.|GUI or CLI.|
|GUI (Graphical User Interface)|n.|图形用户界面|Windows and macOS are GUI-based systems.|Uses icons and windows.|
|CLI (Command Line Interface)|n.|命令行界面|Linux users often prefer the CLI for flexibility.|Text-based input.|
|multitasking|n.|多任务处理|The OS supports multitasking to run multiple applications.|Concurrent execution.|
|multiprocessing|n.|多处理|Multiprocessing uses more than one CPU core.|Parallel processing.|
|resource management|n.|资源管理|Resource management ensures fair CPU and memory allocation.|One of the OS’s main functions.|
|system call|n.|系统调用|Applications use system calls to request OS services.|Interface between user space and kernel.|

|---|---|---|---|---|

|scheduling|n.|调度|The OS uses scheduling to decide which process runs next.|Time-sharing control.|
|input/output control|n.|输入输出控制|The OS manages all input/output operations.|Handles I/O requests.|
|error handling|n.|错误处理|Error handling prevents system crashes.|System reliability function.|
|security|n.|安全|The OS enforces user authentication and access control.|Protects data and privacy.|
|protection|n.|保护|Protection mechanisms prevent unauthorized access.|Related to security.|
|user management|n.|用户管理|The OS manages multiple user accounts.|Handles login and permissions.|

## 4.3 File Systems and Data Organization

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|file system|n.|文件系统|The file system organizes data into files and directories.|Structure for data storage.|
|file|n.|文件|Each file has a unique name and location.|Basic data unit.|
|directory|n.|目录|Directories are used to group related files.|Also called “folder.”|
|folder|n.|文件夹|You can store your documents in a folder.|GUI representation of directory.|
|path|n.|路径|The full path shows the file’s location.|e.g., `/usr/local/bin`.|
|root directory|n.|根目录|The root directory is the top level of the file system.|Represented as `/` or `C:\`.|
|file extension|n.|文件扩展名|The file extension shows its type, like `.txt` or `.exe`.|Indicates format.|
|file permission|n.|文件权限|You need write permission to edit the file.|Read/write/execute control.|
|access control|n.|访问控制|Access control prevents unauthorized file usage.|Security feature.|
|backup|n./v.|备份|Always create a backup before deleting files.|Prevents data loss.|

## 4.4 Process and Memory Management

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|process|n.|进程|Each running application is represented by a process.|Instance of a program.|
|thread|n.|线程|Threads share memory within a process.|Lightweight process.|
|scheduling|n.|调度|The OS uses scheduling algorithms to manage processes.|Round-robin, priority-based, etc.|
|queue|n.|队列|Processes waiting for CPU time are stored in a queue.|Used in scheduling.|
|context switch|n.|上下文切换|Context switching saves and restores process states.|Overhead of multitasking.|
|deadlock|n.|死锁|Deadlocks occur when processes wait for each other’s resources.|Must be avoided.|
|semaphore|n.|信号量|Semaphores are used for process synchronization.|Control shared resources.|
|virtual memory|n.|虚拟内存|Virtual memory extends physical RAM using disk space.|Managed by OS.|
|paging|n.|分页|Paging divides memory into fixed-size blocks.|Part of memory management.|
|swap|v.|交换|The OS swaps inactive pages to disk to free memory.|Swap space on disk.|

## 4.6 System Booting and Shutdown

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|boot|v./n.|启动|The system boots when you press the power button.|Load the OS into memory.|
|reboot|v.|重启|You may need to reboot after installing updates.|Restart the computer.|
|shutdown|v./n.|关机|Always shut down the system properly.|Prevents data loss.|
|BIOS (Basic Input Output System)|n.|基本输入输出系统|BIOS initializes hardware during startup.|Stored in ROM.|
|firmware|n.|固件|Firmware provides low-level control of hardware.|Embedded software.|
|POST (Power-On Self Test)|n.|开机自检|The POST checks hardware before booting the OS.|First startup stage.|
|boot loader|n.|引导加载程序|The boot loader starts the operating system.|e.g., GRUB, Windows Boot Manager.|
|startup sequence|n.|启动顺序|The startup sequence loads system files in order.|Defined in BIOS settings.|
|login|n./v.|登录|You must log in to access your user account.|Authentication step.|
|logout|n./v.|登出|Always log out before leaving a shared computer.|Ends user session.|
