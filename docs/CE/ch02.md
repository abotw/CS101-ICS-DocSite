
# Chapter 2: Computer Hardware

---

## 2.1 Overview of Computer Hardware

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|hardware|n.|硬件|Hardware refers to the physical parts of a computer.|Opposite of software.|
|component|n.|组件，部件|Each hardware component has a specific function.|Includes CPU, memory, storage, etc.|
|motherboard|n.|主板|All major components are connected to the motherboard.|Also called _mainboard_.|
|system unit|n.|主机箱|The system unit houses the main hardware components.|Sometimes called _chassis_.|
|case|n.|机箱|The case protects the internal components.|Metal or plastic enclosure.|
|slot|n.|插槽|Memory modules are inserted into slots on the motherboard.|Expansion or memory slot.|
|port|n.|接口，端口|USB ports are used to connect external devices.|Types: USB, HDMI, Ethernet.|
|cable|n.|电缆|Connect the monitor with an HDMI cable.|Transmission medium.|
|connector|n.|连接器|The cable connector must match the port type.|Physical plug.|
|power supply unit (PSU)|n.|电源供应器|The PSU converts AC to DC for computer components.|Provides stable voltage.|

---

## 2.2 The Central Processing Unit (CPU)

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|CPU (Central Processing Unit)|n.|中央处理器|The CPU executes program instructions.|“The brain of the computer.”|
|processor|n.|处理器|The processor speed is measured in gigahertz.|Synonym of CPU.|
|core|n.|核心|A multi-core processor can handle several tasks at once.|e.g., dual-core, quad-core.|
|clock speed|n.|时钟速度|Clock speed determines how fast the CPU operates.|Measured in GHz.|
|cache|n.|高速缓存|Cache memory stores frequently used data for quick access.|Levels: L1, L2, L3.|
|register|n.|寄存器|Registers store temporary data inside the CPU.|Very small, high-speed memory.|
|ALU (Arithmetic Logic Unit)|n.|算术逻辑单元|The ALU performs arithmetic and logical operations.|Core component of CPU.|
|control unit|n.|控制单元|The control unit directs the CPU’s activities.|Coordinates CPU operations.|
|instruction set|n.|指令集|Each CPU has its own instruction set architecture.|e.g., x86, ARM.|
|heat sink|n.|散热片|The heat sink helps to cool the processor.|Prevents overheating.|

## 2.3 Memory and Storage

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|memory|n.|内存，存储器|The computer temporarily stores data in memory.|Usually volatile (RAM).|
|RAM (Random Access Memory)|n.|随机存取存储器|RAM is cleared when the power is off.|Volatile memory.|
|ROM (Read Only Memory)|n.|只读存储器|ROM stores permanent system instructions.|Non-volatile memory.|
|main memory|n.|主存储器|Programs are loaded into main memory before execution.|Refers to RAM + cache.|
|secondary storage|n.|辅助存储|Hard drives are secondary storage devices.|Non-volatile storage.|
|hard disk drive (HDD)|n.|硬盘驱动器|HDDs use magnetic disks to store data.|Older but cheaper storage.|
|solid-state drive (SSD)|n.|固态硬盘|SSDs are faster and more reliable than HDDs.|No moving parts.|
|flash memory|n.|闪存|Flash memory is used in USB drives and cameras.|Non-volatile storage.|
|optical disk|n.|光盘|CDs and DVDs are types of optical disks.|Read using a laser.|
|capacity|n.|容量|The storage capacity is measured in gigabytes or terabytes.|Common units: GB, TB.|

## 2.6 Storage Media and Data Access

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|storage device|n.|存储设备|USB drives are portable storage devices.|Used for saving files.|
|USB drive|n.|U盘|A USB drive stores data in flash memory.|Also called _thumb drive_.|
|memory card|n.|存储卡|Cameras use memory cards to store photos.|Types: SD, microSD.|

|data transfer rate|n.|数据传输速率|The USB 3.0 transfer rate is up to 5 Gbps.|Also called _bandwidth_.|
|format|v./n.|格式化；格式|Please format the disk before use.|Erases all data.|

## 2.8 Power and Maintenance

|Word|Part of Speech|Chinese Meaning|Example Sentence|Note|
|---|---|---|---|---|
|power supply|n.|电源|The power supply provides electricity to all components.|Abbr: PSU.|

|upgrade|v.|升级|Users can upgrade RAM to improve performance.|Also applies to software.|
|warranty|n.|保修|The computer comes with a one-year warranty.|Manufacturer guarantee.|
